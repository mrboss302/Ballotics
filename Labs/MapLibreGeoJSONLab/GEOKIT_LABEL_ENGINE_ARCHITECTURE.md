### Geographic preparation

Projected parts supply their original even–odd CGPaths. The prototype compares the vertex mean, polygon area centroid with holes subtracted, the 0.3Q center-out interior point, and a bounded best-first search for high clearance from every ring. Each search visits up to 64 cells. The result is an approximation without a global-optimality guarantee. A group considers up to eight parts by bounding area, calculates their true areas, and searches the top three. Multiple candidates per part can serve narrow and multipart geometry. An exact solution for every island and every possible label aspect remains outside this bound. The pole search was written in Swift from the algorithm description. No upstream code or dependency was imported. The upstream implementation uses the ISC license. [Anchor code](../../Packages/BalloticsGeoKit/Sources/BalloticsGeoKit/LabelAnchors.swift) · [Mapbox algorithm](https://github.com/mapbox/polylabel) · [Upstream license](https://github.com/mapbox/polylabel/blob/master/LICENSE)

For each retained interior point the engine precomputes safe centered rectangles at five aspect ratios. For a chosen ratio it scales the x coordinate and measures the minimum L-infinity distance to every ring segment, including hole boundaries. Endpoints and the segment’s intersections with the two diagonals cover the possible minima. A candidate must pass original-path containment before receiving any envelope. Strict rectangular fit plus padding protects against a label crossing a boundary even when its center or all four corners are inside. These conservative envelopes can reject a rectangle that would fit at a different aspect or anchor.

### Measurement and placement

The UIKit adapter measures native medium-weight, monospaced-digit system text. It keeps measurements keyed by string for its one font token and reuses one UILabel per active jurisdiction. It retains UIButton instances for eligible external tiles. It picks dark or light ink by linearized fill luminance. Split-color stripes can need an additional contrast treatment, which remains a visual review item. Expensive anchor preparation runs off the main actor. Changes to paint and text reuse scene-owned anchors and geographic buffers. An unchanged label string retains its measured native dimensions. [Native adapter](ElectoralLabelOverlay.swift)

The resolver orders selected groups first, then descending priority, then stable label ID. Within a group it tries a previously successful candidate first, validates it against the current camera and obstacles, and then tries alternatives. This provides placement continuity during small movements. Zoom limits and eligibility remain explicit. It checks the complete padded rectangle against its envelope, viewport, previously placed labels and any consumer-provided obstacles. Internal full and compact labels, optional callouts with geographic leader points, external tiles and reasoned suppression are distinct outcomes. The electoral client uses internal labels and the external key. Callouts are exercised by a package fixture. Complex leader routing and multi-label global optimization remain open.

Version 1 JSON editorial entries can select a feature-group ID, exact revision, inclusive ISO civil-date interval and region. They can provide projected or region-normalized anchor alternatives, priority, preferred presentation and a typography scale to apply before measuring. The first matching versioned entry wins. A suggested point must lie inside an original member polygon, including holes. The checked historical study uses automatic placement with zero coordinate overrides. The nine-jurisdiction key is separate editorial policy.

The key associates verified text, fill, split indication and selected state with the same geographic inspection callback as a polygon tap. Nonparticipating or absent jurisdictions do not receive a modern tile. Explicitly unresolved participating records can show a question mark with status text. The row is eligible at national zoom below 2×. In region focus it yields to internal labels and geographic inspection. Full production tile layout, larger touch targets, split artwork and physical VoiceOver remain follow-up work.

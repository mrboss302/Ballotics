# Independent audit of Albers Metal 0.3

Base commit `bf373ffb61eac5348407ac02ce0168f16d42d469` matched the remote 0.3 branch before qualification. The standalone lab, its archived results and the pinned source were inspected locally. The new branch preserves that ancestor.

## Components retained

The local upstream libtess2 checkout reported revision `8dbd6483e920311a58c9af10a10beb278efebc36`. Its C source tree, public tessellator header and license matched the vendored files. The original SGI Free Software License B 2.0 notices and app-bundle license resource remain in place. The extra Clang module map belongs to the integration.

Original even–odd paths retain geographic authority. Local Float32 vertices refer to Double regional origins. The mesh keeps explicit original segments for holes, outer boundaries and selection. Opaque shared strokes and exact segment deduplication prevent repeated blending of coincident edges. Part depth preserves geographic stacking. A three-command nonblocking gate bounds submissions, and the default Metal command buffers retain their referenced resources through completion.

Historical preparation still checks cancellation before publication. The live-state check introduced in 0.3 is necessary while a newer date is pending. The new cancellation replay published only the initial and final snapshots and rejected two intervening preparations. ## Restrictions

* GPU completion on the simulator measures completed command work. The physical display, thermal envelope, residency and memory pressure require a signed device run.
* Mesh and style counters describe app-owned logical buffers. Metal driver resources, transient allocations between samples and the lifetime of individual GPU objects remain partially observable.
* The style builder still converts colors and constructs immutable tables on the main actor. The route measures its cost. A production extraction needs allocation and scheduling budgets for representative devices.
* Panel-level culling submits the entire visible region. This limits how much work deep zoom can eliminate on the mainland.
* A CADisplayLink drives camera interpolation, while the UI's state and rendering callbacks can coalesce across frames. The tests cover inverse transforms, overlap membership, direct touches and animated endpoints. Physical gesture latency remains open.
* Source-size limits also need a product policy. Index-width guards protect representation integrity, while decoding, triangulation and shared-buffer staging still consume memory proportional to the source. The measured envelope covers the named workloads.
* A composition must be derived from the cached canonical scene. The lab follows that contract. A separate engine module should enforce the distinction between projected input and composed output in its API.

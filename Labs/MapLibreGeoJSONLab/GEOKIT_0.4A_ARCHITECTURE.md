# BalloticsGeoKit 0.4A

The local Swift package in `Packages/BalloticsGeoKit` builds a library and an independent macOS congressional district viewer. The iOS lab links the local library product through Xcode. Its former projection source is now a module import. Swift command-line regressions compile the package sources directly. Both paths exercise the same implementation. The package has no external package dependencies. [Package manifest](../../Packages/BalloticsGeoKit/Package.swift) · [Reproduction](README.md#balloticsgeokit-04a)

The shared Core Graphics adapter draws the original even–odd paths with their original geographic outlines. The iOS Core Graphics lab and the independent macOS viewer both use it. Apple Core Graphics also supplies CGPath containment and projected bounds. The package therefore currently builds on Apple platforms. An Android port can reuse the contracts and fixtures while implementing path membership, native text measurement and drawing locally. The lab remains the owner of MetalKit, MapLibre, SwiftUI navigation, SwiftData and election data.

## Independent congressional district viewer

`DistrictAtlas` runs separately and opens a native macOS window. Its only input is the 2024 119th Congress Census source. It validates 441 unique records, shows the 436 in the three-region policy, and uses synthetic categorical colors. Search accepts four-digit GEOID or postal abbreviation plus district, such as TX-18. Map selection returns a record through the ordered spatial index. Double-click or search frames the district. National, Alaska and Hawaii controls, scroll pan, Option-scroll zoom and optional detail labels exercise the same package. National label density is bounded by deferring district text until at most 55 features are visible or a district is selected. American Samoa, Guam, Northern Mariana Islands, Puerto Rico and the U.S. Virgin Islands remain outside the presentation. The working thematic layout keeps AK at 0.32 and HI at 1.05 of mainland scale. Each regional projection retains its internal equal-area property. Relative area across regions changes in the thematic composition. Focus masks other regions without changing the source or mesh.

# BalloticsGeoKit 0.4D qualification

**Decision B — qualified with documented restrictions.** The editorial annotation system is ready for further research and owner review.

| Area | Disposition |
| --- | --- |
| Annotation architecture | Stable source rows and geographic identities link one election adapter to the reusable layout contracts and native renderer. |
| Small-state key | Ordered square count artwork with separate 44-point interaction frames. The narrow key wraps with the same reading order. |
| Split allocations | Internal, led and dedicated-key artwork based on qualified units. Groups distinguish quantities, candidates and allocation types. |
| Historical behavior | The 240-scene host study covers all 60 elections. The adapter distinguishes early ballots, allocation slots and presidential EV. Unresolved sources remain available for inspection. |
| Editorial coverage | At 370 × 380 points, visible qualified values rose from 35 to 43 in 1976 and from 30 to 37 in 2024. The Results key retains the remaining qualified values. No authored overrides were needed. |
| Responsive layout | Compact and large phones and the iPad passed portrait and landscape. The iPad landscape Metal drawable measured 2,296 × 839 pixels. The AppKit host exercised wide, compact and shallow dimensions. |
| Accessibility | Native Accessibility Medium and a larger standard text size passed order, targets, selection and regional visibility. The simulator Reduce Motion UI path passed. Physical VoiceOver remains open. |
| Geographic regression | All projection, selection, tessellation and historical source checks passed with identical mesh payloads. |
| Rendering performance | Dense county callbacks remained near 59/s. The companion benchmarks show the native annotation layout distributions, retained outliers and resource release results. |
| Owner acceptance | Remains open. The original reference and native screens are in the private review package. |
| Physical device | Both paired devices were unavailable. Signed Release presentation and accessibility qualification remain open. |

Production gates also cover geographic territories, historical Alaska boundaries, historical result reconciliation, redistribution rights, Ballotics-Data publication and Android parity.

Carry the 0.4D annotation decisions into owner review. Keep 0.4E bounded to county thematic presentation, with signed-device display and accessibility verification when hardware is available.
